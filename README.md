# Signal Overlay

A bookmarklet that injects a clean A/B test metrics panel directly onto any [Convert.com](https://app.convert.com) report page.

## Install

1. Go to the [generator page](https://pennebaj.github.io/signal-overlay/) and drag the **⚡ Signal Overlay** button to your bookmarks bar.
2. Navigate to any Convert experience report page.
3. Click **Signal Overlay** in your bookmarks bar.

## Update

To update the script, edit `signal-overlay.js` and push to `main`. The bookmarklet always loads the latest version.
